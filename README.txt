README - PROJECT REPOSITORY

Title:
Explainable Machine Learning for Vortical Flow Characteristics of a Ranque-Hilsch Vortex Tube: Prediction Accuracy Versus Explanation Fidelity

Authors:
R. Manimaran
S. Vigneshwari

Directory Structure:

data/       - Dataset and input data files used in the study.
models/     - Trained machine-learning models and associated model files.
notebook/   - Jupyter notebooks containing data analysis, model development, and evaluation.
results/    - Outputs generated from the analyses.
  figures/  - Figures and plots generated from the experiments.
  report/   - Analysis reports and supporting outputs.
  tables/   - Tables containing numerical and evaluation results.
LICENSE     - Repository license information.

Purpose:
This repository contains the data, models, notebooks, and results associated with the above research work on explainable machine learning for vortical flow characteristics of a Ranque-Hilsch vortex tube.
